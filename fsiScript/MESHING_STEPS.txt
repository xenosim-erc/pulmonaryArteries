FSI MESHING WORKFLOW - STEP BY STEP
===================================

Driver: meshing.sh INPUT.stl [options]
Each step below names the script or utility that performs it. Every OpenFOAM
utility writes its full output to its own log in the case directory and prints
only a one-line descriptor to the screen.


PRE-FLIGHT
----------
 1. Locate the fsi-env Python          Fail early if VTK/VMTK are unreachable.
 2. Check the helper scripts exist     centerlines, CSV, Gauss, empty patch, refinements.
 3. Check the templates exist          templateMesh and templateCase directories.
 4. Check the meshing utilities        surfaceFeatureEdges, cartesianMesh, checkMesh,
                                       createPatch, mapExtrudeDistance, varExtrudeMesh.
 5. Read the command line              Prompt for every setting not supplied (wall model,
                                       coupling, scale, species, heartbeats, cores,
                                       Windkessel totals) if a terminal is attached.
 5a. Check the run case name           Stop now if run/<name> already exists, before any
                                       meshing is done.
 5b. Confirm the settings              Print every resolved setting and ask to proceed.


GEOMETRY STAGE  (pythonScripts/pulmonary_centerlines.py)
--------------------------------------------------------
 6. Read and clean the STL             Merge duplicate points, triangulate, orient normals.
 7. Smooth the surface                 Windowed-sinc (Taubin) filter; rims held fixed so the
                                       open profiles do not move.
 8. Fill sub-resolution holes          Close any opening below --minimum-profile-radius; a
                                       scan defect must not become a boundary condition.
 9. Find the open profiles             Walk the boundary edges into loops; measure each one's
                                       area and centroid.
10. Extract centerlines                VMTK, sourced from the largest profile to all others;
                                       carries MaximumInscribedSphereRadius.
11. Round the concave saddles          Smooth only the bifurcation crotches, to a target
                                       radius of the local wall thickness / safety factor.
12. Re-extract centerlines             The surface moved, so the diameters are recomputed.
13. Add flow extensions                Extend each profile along its centerline direction by
                                       --extension-diameters, ending in a circular planar rim.
14. Re-establish winding               The extension filter leaves opposed normals; consistent
                                       winding is restored here.
15. Re-measure the profiles            The rims have moved, so they are measured again.
16. Cap the surface                    Triangle fan per opening, each tagged with its own
                                       entity id by the VMTK capper.
17. Name every region                  Largest region becomes 'wall', the cap on the largest
                                       profile 'inlet', the rest 'outlet1..N'. Write
                                       <prefix>_profiles.csv with each rim's patch name.
18. Remesh the caps                    The capper leaves each opening as a ring of
                                       congruent slivers fanned to one centre point;
                                       they are rebuilt as isotropic triangles sized
                                       from the wall they meet. The wall is excluded.
19. Write the surfaces                 <prefix>_uncapped.vtp for thickness mapping, and
                                       <prefix>_capped.stl as one named solid per region.


FLUID MESH
----------
20. Copy the mesh template             templateMesh into the case: fluidMeshing, varExtrudeFunc.
21. Convert surface to FMS             surfaceFeatureEdges; the named solids become named
                                       cfMesh patches, so no patch has to be inferred later.
22. Type the patches                   The FMS carries the type cfMesh puts on each mesh
                                       patch: only the vessel wall is a wall, every
                                       opening is a plain patch.
23. Point meshDict at the FMS          Rewrite the surfaceFile entry for this case.
24. Inject local refinement            add_refinements.py sizes a sphere for every outlet too
                                       small for maxCellSize, snapped to an octree level.
25. Mesh the fluid                     cartesianMesh.
26. Check the fluid mesh               checkMesh -allTopology -allGeometry.
27. Report the patches                 Count wall, inlet and outlets; abort if any named
                                       opening was meshed shut by too coarse a cell size.
28. Insert a zero-face outerWall       add_empty_boundary_patch.py; varExtrudeMesh needs it
                                       as the exposed-patch placeholder.


WALL THICKNESS
--------------
29. Export centerlines to CSV          centerlines_to_csv.py; per-branch arc length and radius.
30. Map thickness to the surface       Gauss.py: smooth diameter along each branch, take the
                                       requested percentage, smooth it over the surface.
31. Project onto the fluid wall        mapExtrudeDistance writes 0/WallThickness; points beyond
                                       --max-mapping-distance warn rather than abort.


SOLID MESH
----------
32. Extrude the solid wall             varExtrudeMesh offsets the fluid wall along its point
                                       normals by the mapped thickness, in 3 layers.
33. Drop the temporary fluid patch      createPatch removes the now-unneeded zero-face patch.
34. Name the solid walls                Exposed face becomes 'innerWall' (conformal with the
                                        fluid wall), the extruded face 'outerWall'.
35. Set the solid ends to patch         Inlet and outlet rings become generic patches (pinned
                                        by the template), in two passes so the type is applied
                                        reliably.
36. Verify the end patches              Confirm the expected count and type were written.


CASE ASSEMBLY
-------------
37. Copy the case template              templateCaseRobin (default) or templateCase into
                                        run/<name>; the name is checked again here.
38. Copy both meshes                    Fluid polyMesh to constant/fluid, solid to constant/solid.
39. Point the inlet at its waveform    0/fluid/U reads humanFlow or pigFlow from
                                        constant/fluid/inletFlow, per --species (asked for;
                                        default human). endTime is set to --heartbeats
                                        (asked for; default 3) times the cycle length, the
                                        last time in that file.
40. Set the core count                 numberOfSubdomains in every decomposeParDict and
                                        --ntasks in run.slurm, per --cores (asked for;
                                        default 16); prints fluid cells per processor.
                                        The Slurm job is named after the run case.
41. Split the Windkessel by area        Totals Rp, Rd, C (asked for) are divided across the
                                        outlets by area^(k/2), k = --flow-split-exponent
                                        (default 2), into 0/fluid/windkesselOutlets. The
                                        outlets are recombined in parallel and checked
                                        against the totals; see log.windkesselOutlets.
42. Scale the run-case meshes           transformPoints -scale on both regions, by
                                        --scale-factor (asked for; default 0.001, mm to m).
                                        The intermediate meshes keep the STL units. No
                                        log is kept; the output is shown only on failure.
43. Record the settings                 run/<name>/meshing.params: the command line, the
                                        repository commit and every resolved setting.
44. Offer to clean up                   Optionally remove the intermediate caseFiles directory.
45. Print the next steps                cd into the case, check the solid mesh, sbatch.


AFTERWARDS - NOT DONE BY THE SCRIPT
-----------------------------------
 *  Check the solid mesh                 checkMesh on constant/solid; look for negative volume
                                        cells at the bifurcations.
 *  Review the case settings             Material properties, Windkessel values per outlet,
                                        inlet waveform, decomposition and cluster paths.
